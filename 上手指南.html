WIKI.HS

给一群人用的知识库网站 · 上手指南

1

先装 Python 依赖

打开命令提示符（Win+R 输入 cmd），执行：

pip install fastapi uvicorn python-multipart

没装 Python？去 python.org 下载 3.10 以上版本，安装时务必勾选 Add Python to PATH。

2

双击启动器

包里有两个启动器，用途不同：

  • 启动本地版.bat —— 在自己电脑上编辑内容，导出静态站，发到 GitHub Pages。不需要服务器。
  • 启动服务器版.bat —— 启动完整网站，浏览器访问 http://127.0.0.1:8081

启动器会自动检测依赖，缺什么会提示你装，中英文自动切换。

3

注册第一个账号

浏览器打开提示的地址，点「注册」，填用户名/邮箱/密码，答一道人机验证题。

验证邮箱后登录 —— 第一个注册的账号自动成为站长， 拥有全部权限，不用再手动配置。

4

部署到公网（可选）

想让别人也能访问，用 Linux 服务器一键部署：

sudo bash deploy.sh

脚本自动装依赖、注册 systemd 服务、开机自启，约 1 分钟完成。

要 HTTPS？加参数：sudo bash deploy.sh --domain 你的域名.com

遇到问题？
启动器窗口一闪而过 = 没装 Python 或没加 PATH；
提示缺依赖 = 执行第 1 步的 pip 命令；
浏览器打不开 = 检查端口 8081 是否被占用。
详细文档见同目录的 README.md 和 CHANGELOG.md
